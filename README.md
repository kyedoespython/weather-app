<h1>Weather4You</h1>

<h2>A Python app that provides real-time weather data for cities all around the world</h2>

<h2 align="center">Features</h2>

<ol>
  <li>Search weather by city name</li>
  <li>Current temperature, humidity, wind speed, and conditions</li>
  <li>Works for locations worldwide</li>
  <li>Simple and easy to use</li>
</ol>

<h2 align="center">Some more information on the project</h2>
<h3>The weather app is an app made to serve one purpose: Provide data on weather conditions all around the world!</h3>
